```txt
详细方案设计及实现顺序

实现顺序

1. 构建系统 + 入口：能编译成 `.so` /可执行，能 `main` 进去。最低门槛。
2. 内存模型：`__pa` / `__va` + 宿主内存池 + memblock 初始化。跑通前的基础。
3. 关中断标志 + 事件注入框架：让 `local_irq_*` 和 IRQ 注入能工作。
4. 时钟 + idle 循环：宿主定时器驱动 tick，idle 不忙等。
5. 调度器 switch_to：`jmp_buf` 切换，能创建内核线程。
6. 控制台 printk：能看到内核启动日志。
7. 块设备后端 + VFS：能挂载根文件系统。
8. 网络后端：virtio-net + TAP。
9. SMP（可选）：多 vCPU 线程 + 宿主锁。
10. 外部用户进程支持（可选）：syscall 拦截 + 用户 mm。
```
